// STATS FORMULA CHEAT SHEET

Simple MeanΣxᵢ / n
Weighted MeanΣ(wᵢxᵢ) / Σwᵢ
Grouped MeanΣ(fᵢmᵢ) / Σfᵢ (mᵢ=midpoint)
Sample VarianceΣ(xᵢ-x̄)² / (n-1)
Population VarianceΣ(xᵢ-μ)² / n
IQRQ3 - Q1
Outlier FencesQ1-1.5·IQR and Q3+1.5·IQR
Percentile Position(p/100)×n
Transform MeanE[aX+b] = a·μ + b
Transform SDSD[aX+b] = |a|·σ
Transform VarianceVar[aX+b] = a²·σ²
Correlation r range-1 ≤ r ≤ +1
⚡ PYQ Pattern Alert: Weighted mean appears in ~80% of qualifiers. Linear transformation (Y=aX+b) for variance is a frequent trick question. Outlier detection with IQR is almost guaranteed.

// MATH FORMULA CHEAT SHEET

Distance√[(x₂-x₁)²+(y₂-y₁)²]
Midpoint((x₁+x₂)/2,(y₁+y₂)/2)
Section (internal m:n)((mx₂+nx₁)/(m+n),(my₂+ny₁)/(m+n))
Section (external m:n)((mx₂-nx₁)/(m-n),(my₂-ny₁)/(m-n))
Slopem=(y₂-y₁)/(x₂-x₁)
Parallelm₁=m₂
Perpendicularm₁×m₂=-1
Point-Line Distance|ax₀+by₀+c|/√(a²+b²)
Vertex x-coordinatex = -b/2a
DiscriminantD = b²-4ac
Quadratic Formulax=(-b±√D)/2a
Parabola opensUp if a>0, Down if a<0
